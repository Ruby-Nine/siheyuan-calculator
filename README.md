# 四合院叠层计算器

明日方舟卫戍协议玩家工具。切换佩佩、奶兔、银灰与 M3 的普通／精锐／不上场状态，实时计算单回合叠层；包含 27 种队友配置、54 种结果速查表。

## 本地使用

直接双击 `index.html` 即可使用，也可以运行 `python -m http.server 4173`，访问 http://localhost:4173 。无需安装前端依赖。修改计算代码后运行 `npm run build` 生成浏览器脚本。

运行 `npm test` 校验全部 54 种计算结果和奇数上限边界。

## 规则

佩佩普通：基础上限9，每次1层；精锐：基础上限18，每次2层。
奶兔普通每次额外1层，精锐额外2层，不占用佩佩上限。
银灰普通75%、精锐150%；M3普通30%、精锐60%。

`L = floor(B × (100 + 银灰百分数 + M3百分数) / 100)`

`N = ceil(L / 佩佩单次叠层)`

`T = L + 奶兔单次额外叠层 × N`

精锐佩佩遇到奇数上限，最后一次自身只加1层，奶兔依然完整触发。假设每回合均能叠满自身上限。

## GitHub Pages

将此目录推送至 GitHub 仓库的 main 分支，在仓库 Settings → Pages → Build and deployment 中选择 GitHub Actions。工作流会先测试，再自动部署静态网页。支持仓库子路径，无后端和外部资源依赖。
